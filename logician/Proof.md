## 解存在性：

```
设三个逻辑学家的数字为（a，b，c）
不失一般性，设a+b=c，n=a+b+c=2c，c>=2，n可以取4，6，8……
最小情形：n=4，（1，1，2），对逻辑学家有解；第二小情形：n=6，（1，2，3）[事实上n=4就已经可以推导任意n]
假设对于n<=2k，对逻辑学家都有解，对于n=2(k+1):
逻辑学家C在某一轮次，将会把B面对的问题分解为(a,b,c)和(a,b,b-a)，对于后一个问题，n=2b<2c=2(k+1)，在之前轮次里对B来说有解，而B未解
故C的数字是c
```

## 轮次解法：

```
问题有解，设k=K(a,b)为最大数字者（不妨设为C）发现自己数字的轮次
若a=b，k=1
若a!=b，设b>a，对于C视角中的B，面对(a,b,c)问题和(a,b,b-a)问题
若C发现经过K(b-a,a)轮，B没有解决问题，在下一轮就能发现自己不是b-a，自己是c
故K(a,b)=K(b-a,a)+1
若qa<b<=(q+1)a，则K(a,b)=q+K(b-qa,a)[通过递推公式得到]
设b-qa=r，r是b减去很多a直到最后数字小于a，q是减去a的次数，会发现q=b//a, r=b%a，就是整数除法的定义
故K(a,b) = b//a + a//(b//a) + ...，直到余数为0
```

### 逻辑学家进阶判断法

给定还没判断出来的轮次和另外两个数字，如何判断自己的数字是不是已经能被判断，以及具体是什么？

```
（取巧：如果是第一个能被判断的，那一定是和，现在看轮次如何触及第一次能被判断）
给定数字a, b以后，自己有可能是a+b或|a-b|，不妨设a<b, b-a > a
可以解K(b-a,a)，这就是保持沉默的轮次，如果发现这个轮次比当前轮次小，说明否定了b-a，也就能判断出自己是b+a
```
